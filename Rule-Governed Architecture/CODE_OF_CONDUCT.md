# rga项目贡献指南 / RGA Project Contribution Guidelines

*Written by 紫心 (Zixin) / January 17, 2026*

---

## 欢迎语 / Welcome
有兴趣一起来玩玩吗？我诚恳的邀请你来到我的项目。我已经准备好了，足够多的工具以及一个有价值的创作目标。或许它还不够完美，但这正不就是我们要一起创造的吗？

Care to join the play? I sincerely invite you to my project. I've prepared plenty of tools and a worthwhile creative goal. Maybe it's not perfect yet, but isn't that exactly why we create together?

## 如何开始 / How to Start
项目文件夹里的根目录下，会详细的介绍具体的每一个模块功能在哪个子目录下，可以先进行查看，找到自己感兴趣的。点击运行，看能不能跑动尝试一下，理解这个项目的有趣的地方。最后查看贡献者指南，在里面添加上自己的名字，然后你就可以开始你自己的创造了。

In the project's root folder, you'll find details on each module's function and its subdirectory. Browse through, find what interests you. Try running it to see if it works and discover what makes the project interesting. Finally, check this guide, add your name, and begin your own creation.

## 行为准则 / Code of Conduct
保证自己在够自由的情况下，请严格的约束自己的道德底线，这是我们共同创造的家园。如果你创造了什么，记得告诉我，我会为它插上名牌。让我们一起来看看，这里能长出多少种不一样的颜色？

While enjoying full freedom, please strictly uphold your moral bottom line—this is a home we build together. If you create something, let me know, and I'll mount a nameplate for it. Let's watch together how many different colors can grow here.

## 提交规范 / Submission Guidelines
每天有一个零号任务，每天可以花五分钟为这个项目里自己想注释补充的代码，添加上自己的注释。定期提交，让更多的人可以更清楚的了解项目的使用方法。

There's a daily “Mission Zero”: spend five minutes adding comments to any code you'd like to annotate. Submit regularly so more people can understand how to use the project more clearly.

## 许可证说明 / License
本项目使用Apache 2.0许可证。希望大家可以一同遵守，营造一个共同愉快的环境，让交流更有意义，让心情更愉快。

This project uses the Apache 2.0 License. We hope everyone can follow it together, fostering a pleasant environment where communication is meaningful and spirits are bright.

## 联系/帮助 / Contact & Help
如果你需要帮助，可以联系我的邮箱，我会在每周定期查看和回复消息。如果我的回复不够及时，可以联系社区，让大家一块看到并提供解决方案。技术有高低，但人的价值平等，我们致力于让每一种“厉害”都闪闪发光。

If you need help, you can contact my email. I will check and reply to messages regularly each week. If my response isn't timely enough, reach out to the community so everyone can see and offer solutions. Skill levels may vary, but human value is equal—we strive to make every kind of “brilliance” shine.
