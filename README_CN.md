Open-learning
=============

开放学习项目是一个综合的复合项目，无论是任何人的想法和提交，社区都会报以认真的态度回应，欢迎新人是最大的社区精神，对待任务是用准确、简洁、清晰的方式解决，把代码用自己的方法实现一个好使的产物是目标。
