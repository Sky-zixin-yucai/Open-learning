Open-learning
=============

The Open Learning Project is a comprehensive and collaborative project. No matter what someone's idea or submission is, the community responds seriously. Welcoming newcomers is the biggest spirit of the community. Tasks are handled in an accurate, concise, and clear way, and the goal is to implement the code in your own way to create a working product.
